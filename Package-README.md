# NServiceBusContrib.Transport.Sqlite

A community SQLite transport package for NServiceBus 10. Queues are tables in a single SQLite database file, accessed through `Microsoft.Data.Sqlite`. Supports native publish/subscribe, native delayed delivery, time-to-be-received, and receive transactions up to `SendsAtomicWithReceive`.
